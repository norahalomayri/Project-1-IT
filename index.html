Project Overview & Context

This production-grade simulation project demonstrates the deployment of a highly secure corporate IT infrastructure environment. It replicates critical compliance and engineering operations required for an IT Systems & Infrastructure Support Specialist, specifically aligning with ITIL frameworks for delivery, change control, and system validation.

Technical Core Walkthrough

1. Directory Services & Network Core Configuration

Configured and promoted a Windows Server 2022 instance to act as the primary Domain Controller governing the root domain forest: ap-infrastructure.local. Core infrastructure services were deployed directly on the host instance:

Subnet Architecture: 192.168.10.0/24
Domain Controller Static IP: 192.168.10.10 (Primary DNS)
Active DHCP Scope Pool: 192.168.10.50 - 192.168.10.200

2. Endpoint Security Hardening via Enforced GPOs

To eliminate unauthorized host configurations and block common data exfiltration methods, a centralized Group Policy Object (Secure_Workstation_Policy) was engineered and linked directly to the organizational units:

  • Mass Storage Restriction: Completely disabled all removable media access (USB storage read/write permissions) at the operating system level.
  • Administrative Environment Lock: Blocked user-level access to the Control Panel and system settings interface.
  • Enterprise Firewall Enforcement: Centrally activated Windows Firewall and restricted end-user override privileges.

3. Data Isolation Governance (NTFS Control Lists) & Print Deployment

Implemented structural department isolation according to the Principle of Least Privilege (PoLP):

  • Created discrete Active Directory Global Security Groups: GG_Engineering and GG_HR.
  • Disabled inheritance flags on child storage blocks (Engineering_Data and HR_Data) to eliminate default domain user privileges.
  • Provisioned explicit NTFS Modify access rights specifically to matching departmental groups, triggering automated Access Denied alerts for unauthorized cross-department lateral movements.
  • Deployed a centralized print queue (HQ-HP-LaserJet-Printer) mapped directly via GPO logic to user profiles.
